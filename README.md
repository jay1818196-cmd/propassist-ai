# PropAssist AI 🏠

Real Estate Customer Support AI Agent — Powered by Claude

## Setup

1. Open `src/App.js`
2. Find line: `const API_KEY = "YOUR_ANTHROPIC_API_KEY_HERE";`
3. Replace with your actual key from console.anthropic.com
4. Deploy to Vercel

## Deploy
- Import this repo on vercel.com
- Click Deploy
- Done!
